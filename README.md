# Acássio Arena — instalador

Instalador Windows do sistema Acássio Arena (agenda, reservas, mensalistas, bar e financeiro).

**Baixar:** veja a versão mais recente em [Releases](../../releases/latest) e baixe o arquivo `.exe`.

Ao abrir, o Windows pode avisar "Editor desconhecido" (o instalador não é assinado):
clique em **Mais informações → Executar assim mesmo**. Atualizar não apaga os dados —
o banco fica em `%APPDATA%\AcassioArena` e é copiado em backup a cada abertura.
